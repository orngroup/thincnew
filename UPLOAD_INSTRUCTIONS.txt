THINC DIGITAL — COMPLETE WEBSITE EXPORT

This package contains the latest website, including the hotel portfolio,
co-investment and management wording, Hanover Square address, London house
photograph, and all page animations. Telephone numbers have been removed.

UPLOAD TO YOUR HOSTING ACCOUNT
1. Extract this ZIP on your computer, or upload it and extract it using your
   hosting provider's file manager.
2. Put index.html, the other HTML files, the assets folder and the ventures
   folder directly inside the website's document root. Depending on your
   provider this may be called public_html, www, htdocs or a chosen folder.
   index.html must be directly inside the document root, not inside an extra
   nested folder.
3. Keep all filenames and folder structures unchanged. Upload the entire
   assets folder: the images and animations depend on it.
4. Connect your domain to the hosting account using the settings supplied
   by that provider, then enable its SSL/TLS certificate and HTTPS redirect.
   The certificate is configured by the host; it is not part of this ZIP.
5. Open the website through its HTTPS address and check each navigation link
   and the animation replay buttons on the three venture pages.

TECHNICAL NOTES
- This is a static website. It needs no database, Node.js, PHP, build command
  or installation step. A standard static web hosting account is sufficient.
- HTML files, CSS, JavaScript, images and animation sheets are included.
- Fonts are requested from Google Fonts over HTTPS. If unavailable, the site
  uses its fallback fonts. All website images and animations are local.
- The contact links open the visitor's email application. There is no
  server-side contact form or built-in comments system.
- Animation playback requires JavaScript. Users who prefer reduced motion
  will see reduced or static animations.
- For local testing, use a local HTTP server or your host's preview URL.
  Direct file:// opening can restrict animation asset loading in browsers.
- UPLOAD_INSTRUCTIONS.txt and ASSET_SOURCES.md are reference documents and
  do not need to be uploaded to the public website folder.
- This export contains no account credentials or hosting-service metadata.
- Uploading this ZIP does not change the currently hosted review website.
